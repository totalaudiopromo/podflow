# Podflow Pricing Comparison & Token Math

Compare compute costs between self-hosted Local CLI (BYOK) and Podflow Cloud SaaS.

## Cost breakdown per 100 Episodes Analyzed

- **Local CLI + Ollama:** $0.00
- **Local CLI + Gemini 1.5 Flash:** ~$0.12 (via BYOK API)
- **Local CLI + Claude 3.5 Sonnet:** ~$1.80 (via BYOK API)
- **Podflow Cloud Pro:** Included in $15/month subscription (no API keys required)
